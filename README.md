# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/drive/1tF_kW_jypEjPXxWzB1t_mUCp7N8pmS6W

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `VITE_OPENAI_API_KEY` in your `.env` file to your OpenAI API key
   - You can copy `.env.example` to `.env` and fill in your API key
   - Get your API key from [OpenAI Platform](https://platform.openai.com/api-keys)
3. Run the app:
   `npm run dev`
